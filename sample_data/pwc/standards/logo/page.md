# Logo

The PwC logo has two components: the wordmark and the Momentum Mark.

Clear space is measured by the height of the lowercase c in the wordmark.
Minimum size is 0.375in in print and 48px in digital.

## Key rules

- Never separate wordmark from Momentum Mark.
- Never recolour, stretch, skew or add effects to the logo.
- Only use assets downloaded from the brand site.
